# T_study

Коллекция небольших frontend-приложений на HTML, CSS и JavaScript. Каждое приложение находится в отдельной папке, имеет собственное состояние и открывается по отдельному адресу.

**[Открыть каталог проектов](https://lostpythonbeast.github.io/T_study/)**

## Приложения

| Проект | Назначение | Основная логика | Ссылки |
|---|---|---|---|
| Internship Board | Учёт откликов и сроков | CRUD, фильтры, валидация и резервные копии JSON | [Демо](https://lostpythonbeast.github.io/T_study/internship-board/) · [Код](internship-board/) |
| Loop Lab | Пошаговая визуализация трёх алгоритмов | Циклы, Map, снимки состояния | [Демо](https://lostpythonbeast.github.io/T_study/loop-lab/) · [Код](loop-lab/) |
| Pocket Budget | Расходы по месяцам и категориям | Расчёты в копейках, месячные итоги и лимиты | [Демо](https://lostpythonbeast.github.io/T_study/pocket-budget/) · [Код](pocket-budget/) |
| Book Nook | Каталог книг с личной полкой | Fetch, состояния загрузки, поиск и избранное | [Демо](https://lostpythonbeast.github.io/T_study/book-nook/) · [Код](book-nook/) |
| Frontend Prep Tracker | Планировщик задач подготовки | Статусы, категории, приоритеты и прогресс | [Демо](https://lostpythonbeast.github.io/T_study/frontend-prep-tracker/) · [Код](frontend-prep-tracker/) |

## Структура репозитория

```text
index.html                 каталог и навигация между приложениями
portfolio.css              оформление каталога
internship-board/          трекер откликов
loop-lab/                  визуализация алгоритмов
pocket-budget/             учёт расходов
book-nook/                 каталог книг
frontend-prep-tracker/     планировщик подготовки
scripts/serve.cjs          локальный статический сервер
verify-all.cjs             общий запуск тестов
```

В четырёх основных проектах `index.html` задаёт разметку, `styles.css` — оформление, `js/app.js` связывает события с интерфейсом. Правила работы с данными вынесены в `js/model.js`; в Loop Lab эту роль выполняет `js/algorithms.js`. Подробнее — в README каждого приложения.

Frontend Prep Tracker использует `script.js` для логики и `style.css` для оформления. Его файлы не связаны с состоянием остальных приложений.

## Локальный запуск

Node.js 22 или новее:

```sh
npm start
```

Адрес каталога: **http://127.0.0.1:8080/**. Установка зависимостей не требуется. Альтернатива — запуск корневого `index.html` через статический сервер, например Live Server. Нужен HTTP-адрес: ES-модули и загрузка JSON не рассчитаны на `file://`.

## Тесты

```sh
npm test
```

25 проверок на встроенном `node:test`: валидация, даты, фильтры, сохранение, денежные суммы и алгоритмы. В Loop Lab один из тестов дополнительно сверяет три алгоритма на всех 363 массивах длиной 1–5 над значениями `-1, 0, 1`. Отдельные тесты запускаются через `npm test` из папки соответствующего проекта. Frontend Prep Tracker в этот автоматический набор не входит.

## Данные и размещение

Данные сохраняются в localStorage; у приложений разные ключи. Серверной базы и синхронизации между устройствами нет. Book Nook загружает фиксированный каталог из своего `data/books.json`. Подробные ограничения описаны в README приложений.

GitHub Pages раздаёт репозиторий как статический сайт: корневой `index.html` — каталог, подпапки — самостоятельные приложения. Все локальные ссылки относительные, поэтому навигация работает с префиксом `/T_study/`. Файл `.nojekyll` отключает обработку содержимого Jekyll.

Лицензии четырёх основных приложений находятся в их папках. Лицензии использованных значков сохранены в `THIRD_PARTY_NOTICES.txt`.
