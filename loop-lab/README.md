# Loop Lab

Визуализатор алгоритмов обработки массива. Перед разбором можно предсказать ответ, затем просмотреть изменения индекса, переменных и Map по шагам.

**[Демо](https://lostpythonbeast.github.io/T_study/loop-lab/)** · [Все проекты](../)

## Алгоритмы и интерфейс

| Алгоритм | Результат |
|---|---|
| Первое уменьшение | Позиция первого числа, меньшего предыдущего; `-1`, если такого нет |
| Самая длинная серия | Максимальная длина последовательности одинаковых соседних чисел |
| Первый уникальный | Первое значение с частотой 1; `NONE`, если все повторяются |

Доступны собственный ввод, проверка прогноза, шаг вперёд и назад, возврат к началу, подсветка строки кода и сохранение отметок верных прогнозов.

## Организация кода

| Файл | Ответственность |

| `index.html` | Выбор алгоритма, ввод, прогноз, массив и панели состояния |
| `styles.css` | Оформление, подсветка элементов и адаптация |
| `js/algorithms.js` | Метаданные задач, разбор ввода, выполнение алгоритмов и снимки шагов |

| `tests/algorithms.test.js` | Проверки результатов и снимков состояния |

## Поток данных

`parseNumbers` возвращает проверенный массив. `buildTrace` выполняет выбранный алгоритм и возвращает `{ answer, steps }`. Каждый шаг содержит индекс элемента, строку кода, пояснение, переменные и копию частот. Интерфейс хранит `stepIndex` и показывает соответствующий снимок. Переход назад меняет индекс снимка, а не выполняет алгоритм в обратном направлении.

Для Map сохраняется отдельный массив пар на каждом шаге. Это не позволяет последующим изменениям частот менять уже записанные шаги. Произвольный код не выполняется; `eval` не используется.

## Запуск и проверки

Из корня: `npm start`, затем `/loop-lab/`. Также подходит статический HTTP-сервер. Из папки приложения:

```sh
npm test
```

Восемь тестов проверяют ввод, крайние случаи, нулевой результат, примеры и независимость снимков. Полный перебор 363 коротких массивов сравнивает три алгоритма с независимыми простыми решениями.

## Ограничения

Ввод — 1–24 целых числа от −9999 до 9999. Сложность в интерфейсе относится к алгоритму; хранение снимков Map может потребовать квадратичную память. Отметки верных прогнозов сохраняются локально и отражают один верный ответ до открытия разбора; они не являются оценкой освоения темы.
