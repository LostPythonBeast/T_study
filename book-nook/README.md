# Book Nook

Каталог восьми произведений русской классики с поиском, фильтрами, сортировкой и личной полкой избранного.

**[Демо](https://lostpythonbeast.github.io/T_study/book-nook/)** · [Все проекты](../)

## Возможности

- Загрузка собственного каталога JSON через fetch.
- Состояния ожидания, ошибки и повторной попытки.
- Поиск по названию и автору, фильтры жанра и объёма.
- Сортировка по названию или автору.
- Избранное с сохранением в браузере.

## Организация кода

| Файл | Ответственность |
|---|---|
| `data/books.json` | Записи каталога и метаданные карточек |
| `index.html` | Поиск, фильтры, вкладки и контейнер карточек |
| `styles.css` | Сетка, обложки из HTML-блоков и адаптация |
| `js/model.js` | Проверка каталога, отбор и сортировка, изменение избранного |
| `js/app.js` | Асинхронная загрузка, состояния интерфейса, DOM и localStorage |
| `tests/model.test.js` | Проверки данных, поиска, фильтров и избранного |

## Поток данных

`loadBooks` получает `data/books.json`, проверяет HTTP-статус, читает JSON и передаёт результат в `validateBooks`. После успешной загрузки интерфейс получает массив `books`. `AbortController` ограничивает ожидание восемью секундами. При ошибке показывается повторная попытка.

`selectBooks` объединяет активные условия и сортирует отфильтрованный массив, не меняя каталог. Полка хранит только id книг. `toggleFavorite` возвращает новый массив id, который сначала сохраняется в localStorage, а затем применяется к интерфейсу. Пользовательский текст выводится через `textContent`.

## Запуск и проверки

Из корня: `npm start`, затем `/book-nook/`. Нужен HTTP-сервер, поскольку используются ES-модули и fetch. Из папки приложения:

```sh
npm test
```

Пять тестов проверяют каталог, поиск, сочетание фильтров, независимую сортировку и избранное.

## Ограничения

Каталог фиксированный и хранится в репозитории; внешние книжные API не используются. Полных текстов, покупки и аккаунтов нет. Обложки не представляют реальные издания. Объём «Короткое» или «Среднее» — условная редакционная группа, не число страниц или время чтения. Избранное хранится только в браузере и не синхронизируется между устройствами.
