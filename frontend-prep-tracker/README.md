# Frontend Prep Tracker

Веб-приложение для отслеживания прогресса в изучении frontend-разработки.

## О проекте

Frontend Prep Tracker — мой учебный проект, созданный для организации самостоятельного обучения frontend-разработке. Приложение позволяет отслеживать изученные темы и контролировать прогресс подготовки.

Проект разработан с использованием HTML, CSS и JavaScript без применения сторонних frontend-фреймворков.

## Возможности

- Отслеживание тем, которые необходимо изучить
- Отметка выполненных задач
- Просмотр общего прогресса обучения
- Удобный интерфейс для организации учебного процесса
- Адаптация интерфейса под разные размеры экрана

## Используемые технологии

- **HTML5** — структура приложения
- **CSS3** — стилизация и оформление интерфейса
- **JavaScript (ES6+)** — логика и интерактивность

## Запуск проекта

1. Склонируйте репозиторий или скачайте его архивом.
2. Откройте файл `index.html` в браузере.
3. Начните пользоваться приложением.

Дополнительная установка зависимостей не требуется.

## Цели проекта

Проект является частью моей подготовки к стажировке frontend-разработчика. В процессе работы я практикую JavaScript, взаимодействие с DOM, обработку пользовательских событий и создание веб-интерфейсов.

В дальнейшем планирую развивать проект и постепенно применять новые знания и инструменты frontend-разработки.
