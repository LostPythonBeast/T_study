# Frontend Prep Tracker

Планировщик задач подготовки к frontend-стажировке. Поддерживает категории, приоритеты, отметки выполнения, фильтры и общий прогресс.

**[Демо](https://lostpythonbeast.github.io/T_study/frontend-prep-tracker/)** · [Все проекты](../)

## Организация кода

| Файл | Ответственность |
|---|---|
| `index.html` | Форма, список задач, фильтры и сводка |
| `style.css` | Оформление, индикатор прогресса и адаптация |
| `script.js` | Состояние задач, localStorage, создание DOM и обработчики событий |

Состояние — массив `tasks`. `loadTasks` читает сохранение и проверяет обязательные поля, `getVisibleTasks` применяет фильтры, `createTaskElement` создаёт строку списка, `render` обновляет список и сводку. Удаление и переключение выполнения обрабатываются через делегирование событий на контейнере списка.

При первом запуске или недоступном сохранении показывается демонстрационный список. Изменения сохраняются в браузере под собственным ключом localStorage. Данные не синхронизируются с сервером или другими приложениями репозитория.

## Запуск

Из корня репозитория: `npm start`, затем `/frontend-prep-tracker/`. Зависимости не требуются. Также подходит Live Server или другой статический HTTP-сервер.

## Ограничения

Прогресс считается как доля выполненных задач. Очистка данных браузера удалит сохранённый список. Автоматических тестов для этого приложения в репозитории пока нет.
