# Frontend Prep Tracker

Небольшой планировщик задач для подготовки к стажировке и изучения Frontend. Учебный проект на чистых HTML, CSS и JavaScript — без фреймворков, сборщиков и сторонних библиотек.

## Возможности

- добавление задач с категорией и приоритетом;
- отметка выполненных задач и удаление;
- фильтрация по статусу и категории;
- подсчёт общего числа задач, выполненных задач и оставшихся шагов;
- индикатор общего прогресса;
- автоматическое сохранение состояния в `localStorage`;
- начальный набор демонстрационных задач и возможность восстановить его кнопкой «Сбросить демо»;
- адаптивная вёрстка для компьютеров и небольших экранов.

## Как запустить

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в актуальном браузере.
3. Добавляйте и отмечайте задачи — отдельная установка зависимостей не требуется.

Можно также опубликовать репозиторий через GitHub Pages: в настройках репозитория откройте **Settings → Pages**, выберите публикацию из ветки `main` и корневой папки `/ (root)`, затем сохраните настройки.

## Структура проекта

```text
frontend-prep-tracker/
├── index.html          # Разметка и элементы интерфейса
├── style.css           # Стили, состояния и адаптивная вёрстка
├── script.js           # Состояние задач, события, фильтры и localStorage
├── README.md           # Описание проекта и инструкция запуска
```

## Технологии и решения

- **HTML5:** семантические секции, форма, подписи полей, кнопки, список задач и доступные названия элементов.
- **CSS3:** Grid/Flexbox, переменные CSS, адаптивные медиазапросы, состояния фокуса и поддержка `prefers-reduced-motion`.
- **JavaScript:** массив объектов как модель данных, работа с DOM, обработчики событий, фильтрация массива, сериализация в JSON и `localStorage`.

Данные хранятся локально в браузере. Они не отправляются на сервер и обычно не синхронизируются между разными браузерами или устройствами. Очистка данных сайта может удалить сохранённый список.

## Что стоит проверить вручную

- добавить задачу с пробелами в начале/конце названия;
- попытаться отправить пустую задачу;
- отметить задачу выполненной, обновить страницу и проверить, что состояние сохранилось;
- проверить фильтры «Все», «В процессе», «Готово» и категории;
- удалить задачу;
- вернуть демо-список и проверить адаптивность на узком экране.

Для самостоятельной подготовки отдельно приложен файл с разбором кода и типичными вопросами к проекту. В публичный репозиторий его добавлять необязательно.

## Дальнейшие идеи

По мере изучения JavaScript можно добавить редактирование задач, сроки выполнения, поиск, сортировку и экспорт списка. Новые функции лучше добавлять постепенно и сначала продумывать, как они повлияют на структуру данных.
