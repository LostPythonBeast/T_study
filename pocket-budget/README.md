# Pocket Budget

Локальный учёт расходов по месяцам и категориям. Приложение показывает историю, общий расход, месячный лимит, остаток и долю каждой категории.

**[Демо](https://lostpythonbeast.github.io/T_study/pocket-budget/)** · [Все проекты](../)

## Возможности

- Добавление, изменение и удаление расходов.
- Сумма, дата, категория и описание записи.
- Выбор месяца, фильтр категории, отдельный лимит каждого месяца.
- Сводка расходов и полоски распределения по категориям.
- Сохранение состояния и демонстрационные записи.

## Организация кода

| Файл | Ответственность |

| `index.html` | Формы расхода и лимита, итоги, распределение и история |
| `styles.css` | Вёрстка и визуализация долей категорий |

| `tests/model.test.js` | Проверки сумм, дат, категорий и сохранения |

## Поток данных

Состояние содержит массив `expenses` и объект `budgets`, где ключ — месяц `YYYY-MM`. `validateExpense` проверяет форму. Суммы хранятся целым числом копеек: `125,50 ₽ → 12550`. Расчёты не складывают десятичные дроби; `Intl.NumberFormat` применяется только при отображении.

`monthSummary` отбирает записи месяца и за один проход считает общую сумму и суммы категорий. Ширина полоски — отношение суммы категории к общему расходу. При отсутствии расходов полоски не создаются.

При редактировании объект заменяется по id. Состояние меняется после успешной записи в localStorage. Фильтр категории ограничивает историю; сводка и распределение по-прежнему относятся ко всему выбранному месяцу.

## Запуск и проверки

Из корня: `npm start`, затем `/pocket-budget/`. Из папки приложения:

```sh
npm test
```

Четыре теста проверяют точность копеек, ошибочные суммы, даты, итоги месяца и структуру сохранения.

## Ограничения

Только положительные расходы в рублях, не больше двух десятичных знаков. До 2000 записей. Доходы, возвраты, переводы и банковские интеграции не учитываются. Данные сохраняются только в браузере; штатного экспорта истории нет. При повреждённом сохранении доступно скачивание исходного текста перед заменой.
