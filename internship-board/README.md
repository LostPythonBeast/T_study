# Internship Board

Трекер откликов на стажировки: компании, вакансии, этапы отбора, сроки и следующие действия. Приложение работает на HTML, CSS и JavaScript, без фреймворков и зависимостей.

**[Демо](https://lostpythonbeast.github.io/T_study/internship-board/)** · [Все проекты](../)

## Возможности

- Добавление, редактирование, удаление и отмена последнего удаления.
- Шесть статусов отбора, поиск, фильтр и две сортировки.
- Счётчики откликов, выделение прошедших сроков, ближайший срок.
- Сохранение в браузере, экспорт и восстановление JSON-копии.
- Демонстрационные записи с вымышленными компаниями.

## Организация кода

| Файл | Ответственность |
|---|---|
| `index.html` | Разметка списка, фильтров, статистики и модальной формы |
| `styles.css` | Внешний вид, мобильная вёрстка и навигация к каталогу |
| `js/model.js` | Статусы, валидация, даты, отбор записей и проверка JSON-копии |
| `js/app.js` | Обработчики формы и кнопок, localStorage и создание карточек DOM |
| `tests/model.test.js` | Проверки правил работы с данными |

## Поток данных

Состояние — массив объектов `entries`. Форма передаёт данные в `validateEntry`. При добавлении, редактировании или удалении создаётся новый массив. `persist` сначала записывает его в localStorage, затем обновляет состояние и вызывает `render`. Неудачная запись показывает сообщение и не применяет изменение.

`selectEntries` фильтрует и сортирует копию списка, не изменяя исходный массив. Даты хранятся строками `YYYY-MM-DD` и сравниваются без преобразования в UTC.

Импорт сначала проверяет все записи и их идентификаторы, затем заменяет список после подтверждения. Формат копии: `{ "version": 1, "entries": [...] }`. Пользовательский текст выводится через `textContent`; ссылки допускают только `http:` и `https:`.

## Запуск и проверки

Из корня репозитория: `npm start`, затем `/internship-board/`. Также подходит любой статический HTTP-сервер.

Из папки приложения:

```sh
npm test
```

Восемь тестов проверяют поля, URL, календарные даты, сроки, фильтры, сортировку и повреждённый импорт.

## Ограничения

До 1000 откликов; импортируемая копия — не больше 3 МБ. Данные принадлежат браузеру и адресу сайта, не синхронизируются между вкладками и устройствами. Очистка хранилища удаляет записи; для переноса доступен экспорт. Напоминания о сроках показываются только внутри приложения.
